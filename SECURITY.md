# Security

Please report security problems privately to **security@pocketwebcam.com**, not in a public
issue. Say what you found, how to reproduce it, and which app and version it affects.

You'll get an answer within a week. Once a fix ships, we're happy to credit you in the
release notes if you'd like.

Most interesting to us: anything that lets someone other than a paired computer see or
control the phone's camera or microphone (pairing, TLS and the protocol are described in
[PROTOCOL.md](PROTOCOL.md)), and anything the installers or the desktop app do with more
permissions than they need.

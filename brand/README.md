# Pocket Webcam brand

## Logo

| File | Use |
|---|---|
| `logo.svg` | Master logo ("C · Lens"). Scales to any size. |
| `profile-1024.png` | Profile picture: Instagram, TikTok, YouTube, Bluesky |
| `profile-400.png` | Profile picture: X/Twitter, Reddit |
| `logo-a-yellow.svg`, `logo-b-dark.svg` | Earlier alternatives (not in use) |
| `preview.html` / `preview.png` | Circle-crop comparison of the three options |

Platforms crop profile pictures to a circle; the logo is designed to sit inside it.

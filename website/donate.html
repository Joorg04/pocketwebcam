Next: a built-in microphone on Windows

On Linux, your phone’s microphone already shows up as Pocket Webcam Microphone. Windows only lets an app add a microphone through a driver, and Windows only loads drivers that Microsoft has signed. To get a driver signed, a developer needs a code-signing certificate that costs a few hundred dollars every year.

Donations pay for that certificate. With it, the Windows version comes as one download: the app, the camera and the microphone, installed together. No extra tools to set up.

What donations pay for

  • The Windows microphone. The signed driver described above.
  • A signed Windows installer. The same certificate stops Windows from warning “Windows protected your PC” when you install the app.
  • Keeping it free. Hosting, store fees and test devices.

Use your iPhone as a webcam on Windows 11

Pocket Webcam sends your iPhone’s camera to your Windows PC over Wi-Fi and shows it as a regular webcam: in Zoom, Discord, OBS and your browser. Free, no watermark, no account.

Status: preview. The Windows app is new and still being tested, so expect rough edges. It needs Windows 11. The phone’s microphone isn’t available on Windows yet (why). The iPhone app is in beta on TestFlight: join the launch list to get an invite.

How it works

  1. The iPhone app encodes the camera in hardware (H.264 or HEVC) and announces itself on your Wi-Fi.
  2. The Windows app finds the phone, decodes the video and sends it to a virtual camera called Pocket Webcam (Windows Virtual Camera), using the virtual camera support built into Windows 11.
  3. Any app that lists your webcams can pick it.

What you need

  • An iPhone with iOS 17 or later (an Android version comes later)
  • A 64-bit PC with Windows 11
  • Both on the same Wi-Fi network

Install

Download for Windows 11 (33 MB)

  1. Run PocketWebcam-Setup-0.2.0.exe. Windows may say “Windows protected your PC” because the preview isn’t signed yet: choose More info, then Run anyway.
  2. Allow the administrator prompt. Setup needs it once, to install the virtual camera and a firewall rule that lets the app find your phone on private networks.
  3. Open Pocket Webcam from the Start menu.

To check that the download is complete and unchanged, run this in PowerShell in your Downloads folder. It should print the SHA-256 below.

Get-FileHash .\PocketWebcam-Setup-0.2.0.exe
9C37CDFE629BAA96F3D9CF5F601886B57BC050AC7D7DBBDE7F31FD7CBE6DEF76

Connect your iPhone

  1. Open Pocket Webcam on the iPhone, on the same Wi-Fi as your PC.
  2. The first time, pair them: the desktop app shows a QR code. On the iPhone, tap Pair with a computer and scan it (or pair with a 6-digit code instead). After that they connect by themselves.
  3. Press Start virtual camera, then choose Pocket Webcam (Windows Virtual Camera) in your call, streaming or browser app.

Discovery uses mDNS (UDP 5353) and the video uses TCP port 7310. If your phone doesn’t show up, see the questions below and the help page.

Windows questions

Does it work on Windows 10?

No. The virtual camera uses a camera API that Windows 11 added, so the installer needs Windows 11. A Windows 10 version may come later.

Can I use the phone’s microphone on Windows?

Not yet. Windows only accepts a new microphone from a driver that Microsoft has signed, and the signing certificate costs money every year. It’s the next thing donations pay for. Until then, use your computer’s own microphone.

Why does Windows say “Windows protected your PC”?

The preview installer isn’t code-signed yet, so SmartScreen doesn’t know it. Choose More info, then Run anyway. Signing comes with the same certificate as the microphone driver.

Why doesn’t the desktop app find my phone?

The installer allows phone discovery (mDNS, UDP port 5353) on private networks only. If Windows treats your Wi-Fi as a public network, set it to private in Settings → Network & internet, or open “Connect by IP address” in the desktop app and type the address your phone shows. Guest networks often block devices from seeing each other.

Which apps can use the camera?

Apps that use the standard Windows camera list, such as the Camera app, browsers, Zoom, Discord and OBS. It shows up as “Pocket Webcam (Windows Virtual Camera)”. This is a preview, so testing with more apps, including Microsoft Teams, is still going on.

How do I uninstall it?

Settings → Apps → Installed apps → Pocket Webcam → Uninstall. That removes the app and the virtual camera. Your settings stay in your user folder.

Not on Windows?

There’s a Linux setup guide, and an Android version comes after the iPhone launch. Coming from another app? Compare Pocket Webcam with Camo, EpocCam or iVCam.
